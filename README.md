# موقع شام الأصيل

موقع المطعم (منيو، سلة، طلب على الواتساب) + لوحة تحكم مخفية. HTML و CSS و JavaScript من غير build، و Firebase للبيانات.

## صفحات الموقع

- `index.html`: المنيو والعروض. الضغط على أي صنف يفتح تفاصيله (صورة، شرح، حجم، كمية، تقييمات).
- `order.html`: صفحة الطلب المستقلة (السلة، البيانات، الإرسال على الواتساب).
- `credits.html`: مصادر الصور اللي من النت.

## الصور والشرح

- صور المطعم نفسه للأصناف اللي ليها صور، والباقي صور من Flickr **مش من مطبخ المطعم** برخص CC BY / BY-SA / CC0 (ملفاتها `stock-*.webp`). مافيش علامة عليها في الموقع، ومصادرها في `assets/img/credits.json`. **لازم تفضل صفحة حقوق الصور موجودة** طول ما الصور دي مستخدمة. الأفضل تستبدلها بصور حقيقية من الداشبورد.
- شرح الأصناف مكتوب من اسم الصنف وقسمه (`assets/js/seed-details.js`). **راجعه مع صاحب المطعم** قبل النشر، خصوصاً المكونات.

## التقييمات

الزبون يقيّم من تفاصيل الصنف (نجوم واسم ورأي)، والتقييم مايظهرش غير بعد موافقة الأدمن من تبويب «التقييمات». محتاجة Firebase: من غيره قسم التقييمات مخفي. «تقييم واحد لكل صنف» متطبق على جهاز الزبون بس، فالمراجعة قبل النشر هي الحماية من الإزعاج.

## لوحة التحكم

المسار: **`/manage-bwn6gq3v/`** (بعد النشر: `https://<project>.web.app/manage-bwn6gq3v/`).

مفيش أي رابط ليها في الموقع ومعلّمة `noindex`. **اخفاء الرابط مش هو الحماية**: الحماية من تسجيل الدخول وقواعد `firestore.rules`.

| التبويب | بتعمل فيه إيه |
|---|---|
| الطلبات | طلبات آخر 30 يوم لحظياً، اتصال بالزبون، الحالة، مسح القديم |
| التقييمات | موافقة وإخفاء ومسح (من غير تعديل كلام الزبون) |
| الإحصائيات | النهارده / 7 / 30 يوم (من المتأكد والمسلّم بس) |
| المنيو | إضافة وتعديل وحذف، الأسعار وأسماء الأحجام، خلصان، مميز، الصورة |
| العروض | إضافة وتعديل وإخفاء |
| الإعدادات | الأرقام، رقم الواتساب، العنوان، المواعيد، «مقفول دلوقتي» |

> الطلب المسجل معناه إن الزبون ضغط «ابعت»، مش إن الرسالة وصلت.

## التشغيل على جهازك

معاينة الموقع من غير Firebase (بيعرض المنيو الأساسي):

```powershell
node scripts/serve.mjs 4173
```

التجربة الكاملة بمحاكي Firebase (محتاج Node 20+ و **Java 21+**):

```powershell
npm install
```

```powershell
npm run emulators
```

```powershell
npm run seed
```

الموقع على `http://localhost:5000` والداشبورد على `http://localhost:5000/manage-bwn6gq3v/`. حساب الأدمن التجريبي مكتوب في `scripts/seed-upload.mjs` وشغال على المحاكي بس.

لو Java مش متثبتة على الجهاز: حط JDK 21 مفكوك جوه مجلد `.tools/`، أو اضبط المتغير `SHAM_JAVA_HOME`.

## النسخة التجريبية على GitHub Pages

الفرع `main` فيه الكود، والفرع `gh-pages` فيه النسخة المبنية (مخفية من محركات البحث وعليها شريط «نسخة تجريبية»). علشان تبنيها من جديد في مجلد فاضي:

```powershell
node scripts/build-demo.mjs .demo https://med-i1.github.io/sham-alaseel/
```

بعدها ارفع محتوى المجلد على فرع `gh-pages`. من غير Firebase: الطلب بيروح على الواتساب بس، ولوحة التحكم والتقييمات مش شغالين.

## ربط المشروع الحقيقي (تعمله بنفسك)

1. اعمل مشروع على <https://console.firebase.google.com> (الباقة المجانية Spark).
2. فعّل **Firestore** (production mode) و **Hosting**.
3. **Authentication** > Sign-in method > فعّل Email/Password.
4. Authentication > Users > أضف مستخدم الأدمن بباسورد قوي.
5. Authentication > Settings > User actions > **الغي Enable create (sign-up)** علشان محدش يسجل لنفسه.
6. Firestore > أنشئ مجموعة `admins` ومستند الـ ID بتاعه هو **User UID** للأدمن (أي حقل، مثلاً `name`).
7. Project settings > Your apps > Web > انسخ `firebaseConfig` وحطه في `public/assets/js/firebase-config.js` مكان `null` في `PROJECT_CONFIG`. (الإعدادات دي مش سرية. **ماتشاركش أي باسورد**.)

النشر:

```powershell
npx firebase login
```

```powershell
npx firebase deploy --project <project-id>
```

بعدها: ادخل الداشبورد ← المنيو ← **ارفع المنيو الأساسي**.

## بعد النشر

- اتأكد إن رؤوس الحماية وصلت (محاكي الاستضافة على ويندوز مابيطبقهاش، فماتجربتش محلياً). المتوقع تشوف `x-robots-tag: noindex`:

  ```powershell
  curl.exe -I https://<project>.web.app/manage-bwn6gq3v/
  ```

- حدّث رابط الموقع في خرائط جوجل وفيسبوك والمدونة.
- في `public/index.html` خلّي `og:image` رابط كامل (`https://<project>.web.app/assets/img/og.jpg`).
- إعلانات AdSense تفضل على المدونة.
- أيقونتي فيسبوك وإنستجرام في المدونة الحالية بيودّوا على حسابات صاحب القالب، ورابط الواتساب رايح لرقم الشكاوى بصيغة غلط (`wa.me/+01090000345`): صلّحهم.

## محتاج تأكيد من صاحب المطعم (كله يتعدل من الداشبورد)

1. **أسماء الأحجام**: أغلب الأصناف ليها أكتر من سعر من غير عناوين، فبتظهر «حجم 1 / 2 / 3».
2. **أسعار مشكوك فيها** (بتظهر «اسأل عن السعر» من غير زر إضافة): شاورما لحم «140 115»، باكيت بطاطس وكلو سلو «65 50»، باستا الأفرن «0 120»، الحواوشي، ميكس جريل.
3. هل الأسعار محدّثة؟ (أغلب منشورات المدونة من 2023)
4. العروض السارية، الأصناف المميزة، مصاريف ومناطق التوصيل.
5. إن 01157879997 عليه واتساب، حساب إنستجرام الحقيقي، وملف اللوجو الأصلي.
6. ملاحظات من النقل: بوكس شاورما فراخ 12 قطعة (250) قريب جداً من 7 قطع (240)، ونصوص اتعدلت إملائياً (مثلاً «بلونينز» بقت «بولونيز»).

## حدود معروفة

- الباقة المجانية ليها حدود يومية للقراءة والكتابة.
- أي زائر يقدر يضيف طلب (ده المطلوب)، فممكن تحصل طلبات إزعاج. القواعد بتحدد الحقول والأطوال وعدد السطور، لكن مابتفحصش محتوى كل سطر. لو حصل إزعاج نضيف Firebase App Check.
- مفيش دفع أونلاين ولا حسابات للزباين ولا تتبع للطلب.
